# Phase 6 prototype: score and diagnosis (offline)

Generated by `phase6_model.py` on 2026-11-15. Offline only: nothing here changes the live scorer. Inputs: `baselines/phase5_2026-11-15_v3/checkpoint_measurements.csv` with automatic key frames (`anchor_set = auto`, as the product would run), Alex's scores, Cam's quick check, both coaches' swipe pairs.

**Read this first.** 17 clips from 13 players. This is a feasibility check, not proof: the intervals below are wide, the strong clips were nearly all filmed in one indoor net lane and the weak ones outdoors or in a sports hall (the venue/camera confound), and the coaches' scores were known when the plan was written. The question it answers is "is this worth building on more clips?", not "does it work?".

Left out: Female_Average.mp4 (no Phase 5 measurements; filmed_correctly = N).

## What was built

- **Score:** a linear Bradley-Terry model with features (pairwise logistic regression, L2 penalty lambda = 0.1 on the mean log-loss, no intercept, weights constrained to be >= 0 because every feature is oriented so that higher = better). Penalty, constraint and features were fixed before any fit.
- **Features** (rule: pass test 3 and coverage; best automatic-key-frame Spearman in each pillar): M05 (access, C05, higher better), M01 (tracking, C01, higher worse), M11 (stability, C11, higher worse), M12 (flow, C12, higher better). Standardised with the training clips' median and IQR, clipped at +-3; a missing value counts as no difference.
- **Training pairs:** Alex's scores imply 136 pairs, Cam's 118 (ties skipped), plus 36 + 36 swipe pairs (326 in all; 41 more involve the clip with no measurements).
- **Evaluation:** leave one player out (13 folds; Cam's four clips leave together, as do Alex's two). A held-out player is in no training pair and no scaling statistic (checked in code on every fold). Intervals: 95% bootstrap over players (2000 resamples); they resample the evaluation, not the fit, so they are if anything too narrow. With 13 players (one of them holding 4 of the 8 strong clips) the bootstrap is lumpy and the intervals are skewed; read them as rough.

## Conclusions

1. **Order.** Out of fold, the model's Spearman is 0.20 with Alex and 0.14 with Cam; the four-rule scorer's is 0.66 and 0.66; a constant scorer has none. The point estimates favour the four-rule scorer, but the intervals on the difference include zero, so on 17 clips neither is shown to be better. Held-out pairs correct: model 62%, four-rule 71%, constant 50%.
2. **Confound.** A scorer that only knows the venue (indoor net lane = 1, else 0) reaches 0.87 with Alex and 0.87 with Cam. Any number in the order table has to beat that to mean much on these clips; the new clips must mix venues within tier.
3. **Diagnosis.** At the provisional threshold the model names Cam's main fault on 0 of 16 clips (chance with the same marginals: 0.8); Cam's fault is among the model's failed checkpoints on 2 of 11 clips; it says F00 on 0 of the 5 clips where Cam does. With eleven checkpoints each failing about a quarter of good clips by construction, a clip fails 2.9 on average, so the earliest-in-chain rule mostly picks an early checkpoint. The thresholds need coach checkpoint ratings, not tier percentiles.
4. **Where the weakness is.** With validated key frames in place of automatic ones the same model reaches 0.27 / 0.23 (automatic: 0.20 / 0.14), so key-frame error is not the main limit. The measurements themselves carry little of what the coaches see in the overall score: no single one reaches 0.4 with either coach, and M02, M04, M06 run against their registered direction with both coaches (as the Phase 5 log already noted for v1). They are not flipped here: flipping them on 17 clips would fit noise and the venue.
5. **Calibration.** Leave one player out, the calibrated number is off the coaches' average by 25.7 points on average, against 20.3 for the four-rule scorer and 23.6 for a constant. It inherits every error in the order, and with 17 clips the map is coarse.
6. **Status.** Feasibility only, and on this evidence the prototype is not ready to replace the four-rule scorer or to name a priority fix. The machinery (pairs, grouped evaluation, sign constraints, chain-order diagnosis with F00) works and is tested, so it can be rerun unchanged as clips and checkpoint ratings arrive.

## What would make it better

- **More players, mixed venues within tier.** 13 players cannot separate technique from filming conditions; the venue alone orders these clips better than any measurement model. About 60 clips from 30+ players, with good and weak batters in each venue, is the plan's next step (at 60 clips a Spearman of 0.7 has an interval of about 0.54 to 0.81).
- **Coach checkpoint ratings (2 / 1 / 0 / X).** They would (a) decide test 1 for each measurement, so only measurements that track the coaches enter the model; (b) replace the tier-percentile thresholds with thresholds fitted to the coaches' own fail/pass calls; (c) let the diagnosis be checked checkpoint by checkpoint, not only against one main fault.
- **Measurements for what coaches name but this run cannot measure:** F13 (trigger), F14 (top half closes), F15 (moves across, not out), F16 (weight over the ball), and a flow measurement to replace M09. Phase 5 v5 has registered M14 (front-foot landing against the start of the downswing, the research note's best-supported marker), M15, M16 and M17 but not yet run them on the clips; once they pass the entry tests, rerun this script on the v5 table (the feature rule picks them up automatically).
- **Pose quality on small, distant batters** (RTMPose in place of MediaPipe; see methods notes): several beginner clips have values set by a few bad frames, and Ollie P (two figures in shot) gets the lowest strength despite a Good Club score.
- **More swipe pairs, chosen actively**, so the training signal is not dominated by pairs implied by two sets of scores on the same 17 clips.
